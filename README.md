# VPN на роутере для iPhone

Мастер для iPhone настраивает автоматический выбор VPN-сервера в домашней сети Keenetic или Netcraze. На совместимой модели сервер выбирает сам роутер. Для младших моделей можно подготовить отдельный постоянно включённый шлюз. После настройки мастер можно закрыть.

## Как выбрать установку

Найдите индекс модели на наклейке, например KN-1810 или NC-1812. У разных поколений Ultra или Giga могут отличаться процессор, хранилище и набор компонентов. [Пример Ultra KN-1810](https://support.keenetic.com/tr/ultra/kn-1810/tr/18482-installing-opkg-entware-in-the-router-s-internal-memory.html) · [Пример Ultra NC-1812](https://support.netcraze.ru/ultra/nc-1812/ru/20980-installing-the-entware-repository-on-a-usb-drive.html).

| Возможности конкретной модели | Как подключить |
|---|---|
| Доступны Entware, постоянное хранилище, WireGuard и «Клиент прокси» | В мастере выберите **Проверить роутер**. На свежей установке перед вводом ключа мастер проверяет архитектуру, компоненты и свободное место. |
| Есть «Клиент прокси», Entware отсутствует | Выберите **Настроить отдельный шлюз**. На постоянно включённом ПК или NAS понадобится Docker Compose с Linux-контейнерами. Домашний роутер подключается к шлюзу по SOCKS5. |
| Есть Ethernet WAN с ручной настройкой IPv4, но нет ни Entware, ни «Клиента прокси» | Тот же мастер создаёт комплект для **кабельного подключения**. Нужен постоянно включённый Linux-шлюз с интернетом и отдельным проводным портом к WAN роутера. Смотрите `ethernet/README.md` внутри персонального архива. |

У отдельных моделей для Entware доступна внутренняя память, у других используется внешний накопитель. Производитель описывает аппаратные ограничения OPKG и настройку компонента «Клиент прокси». [Ограничения OPKG](https://support.netcraze.ru/ultra/nc-1812/ru/49454-functional-limitations-of-devices.html) · [Внутреннее хранилище](https://support.netcraze.ru/giga/nc-1013/ru/18482-installing-opkg-entware-in-the-router-s-internal-memory.html) · [Штатный SOCKS5 на примере Air NC-1613](https://support.netcraze.ru/air/nc-1613/ru/49443-proxy-client.html).

## Установка на самом роутере

1. Подключитесь к домашней сети роутера. Для первой настройки понадобятся SSH-порт Entware, его пользователь с правами администратора и пароль. Сверьте показанный мастером отпечаток с отпечатком, известным владельцу роутера.
2. Откройте мастер, укажите LAN-адрес и войдите в Entware. Введите любое имя подписки, затем вставьте ссылку из Happ или INCY. Если провайдер привязывает подписку к устройству, используйте предназначенный для роутера допуск и выданные провайдером параметры.
3. Нажмите **Добавить и проверить**. Для автоматического режима нужны как минимум два разных серверных профиля, которые распознаёт AWG Manager. Мастер сверяет состав группы на роутере и отправляет через неё запрос HTTPS.
4. Чтобы переключить текущий телефон или ПК, нажмите **Подключить это устройство к VPN**. Мастер определяет устройство по его локальному SSH-соединению и проверяет новую привязку. Остальными устройствами владелец управляет в разделе **Приоритеты подключений** на роутере.

## Установка на отдельном шлюзе

1. Закрепите за ПК или NAS постоянный адрес в домашней сети. На первом экране мастера нажмите **Настроить отдельный шлюз**. Введите адрес этого компьютера, порт SOCKS5 и свою подписку. Для этого шага пароль SSH роутера не нужен.
2. Нажмите «Сохранить архив шлюза» и выберите папку в системном окне «Файлы». Архив содержит ключ подписки и пароль прокси. Распакуйте его на шлюзе. Порядок запуска, проверки и остановки указан в README.md внутри архива.
3. В меню роутера **Другие подключения → Прокси-подключения** добавьте SOCKS5 по адресу, порту, логину и паролю из персонального архива. В **Приоритетах подключений** назначьте его нужным клиентам. Самому шлюзу нужен обычный выход к провайдеру для связи с серверами подписки.
4. На шлюзе проверьте состояние службы по инструкции из архива, затем откройте сайт с выбранного домашнего устройства. Переключение по доступности выполняет шлюз. При его выключении эта VPN-группа перестаёт обслуживать устройства. [Настройка подключений по инструкции производителя](https://support.netcraze.ru/air/nc-1613/ru/49443-proxy-client.html).

Для отдельного шлюза используйте обычную HTTP(S)-подписку, совместимую ссылку импорта или список поддерживаемых ссылок на серверы. Для закрытого Happ Crypt в этом режиме потребуется обычная ссылка от провайдера. Обновления списков по URL и правила обработки неподдерживаемых записей описаны в персональном архиве. Для нового владельца пересылайте общий архив приложения.

В кабельном варианте роутер получает интернет по своему обычному проводному WAN. На Linux нужен локальный Docker Engine с TUN и поддержкой macvlan. Транзит предусмотрен для IPv4 TCP и UDP. До переключения сохраните настройки WAN и проверьте, что Linux-шлюз сам выходит в интернет через отдельное соединение. Шаги запуска, адреса, проверка и возврат указаны в `ethernet/README.md`. [Требования Docker для macvlan](https://docs.docker.com/engine/network/drivers/macvlan/).

## Форматы и совместимость

Можно вставить обычную ссылку HTTP(S), ссылку импорта Happ или INCY с адресом подписки внутри, а также список отдельных ссылок в обычном тексте или Base64. Подписка может объединять серверы разных протоколов, например VLESS, Trojan, Shadowsocks и Hysteria2. Для защищённых ссылок Happ у AWG Manager должен быть подходящий ключ провайдера. Доступ к подписке и лимит устройств задаёт провайдер. [Поддерживаемые форматы AWG Manager](https://github.com/hoaxisr/awg-manager/blob/v2.19.25/internal/singbox/subscription/service.go).

Для установки непосредственно на роутере требуются KeeneticOS или NetcrazeOS с компонентами **Клиент прокси** и **WireGuard**, постоянное хранилище с Entware и доступ к его SSH. На новом устройстве сначала подготовьте Entware по инструкции для конкретной модели. Мастер проверяет архитектуру через OPKG. Для новой установки предусмотрены пакеты AWG Manager 2.19.25 для aarch64-3.10, mipsel-3.4 и mips-3.4. [Пример установки Entware на Giga NC-1012](https://support.netcraze.ru/giga/nc-1012/ru/20980-installing-the-entware-repository-on-a-usb-drive.html) · [Пакеты AWG Manager для трёх архитектур](https://github.com/hoaxisr/awg-manager/releases/expanded_assets/v2.19.25).

Режим URLTest проверяет доступность контрольного URL и задержку. Для новой группы мастер задаёт интервал 60 секунд и допуск 50 мс. Список по ссылке обновляется раз в час. Вставленный вручную список остаётся фиксированным. Время восстановления зависит от момента сбоя, тайм-аутов и оставшихся рабочих узлов. Уже открытое соединение может потребовать повторного подключения. [Описание URLTest](https://sing-box.sagernet.org/configuration/outbound/urltest/).

## Запуск на iPhone

Откройте терминал на Mac с Xcode, Go версии из корневого `go.mod` и XcodeGen. Из корня репозитория выполните `bash platform/ios/build.sh`. Скрипт соберёт XCFramework для устройства и симулятора, затем создаст `platform/ios/RouterSetup.xcodeproj`.

Откройте проект в Xcode, выберите схему RouterSetup и симулятор iPhone. Для установки на собственный iPhone задайте свою команду Apple Developer в Signing & Capabilities и уникальный Bundle Identifier, затем запустите сборку на подключённом устройстве. При первом обращении к роутеру разрешите доступ к локальной сети.

Задание GitHub Actions `iOS simulator` проверяет Go-код, собирает приложение для процессора iPhone и запускает XCTest на симуляторе. После успешного выполнения `iOS-simulator-app` содержит сборку для симулятора, а `iOS-device-unsigned` содержит IPA для последующей подписи владельцем. Для установки на физическое устройство через Xcode используйте свою команду подписи и совместимый профиль подготовки.

Проверить настройки или вернуть прежний маршрут можно в веб-панели роутера. Для устройства выберите его предыдущую политику доступа. Перед удалением подписки в AWG Manager проверьте, какие устройства используют связанный с ней интерфейс Proxy.
