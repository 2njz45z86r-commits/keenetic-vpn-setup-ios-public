Подключитесь к домашней сети роутера.

Подключение к роутеру

Укажите адрес роутера и порт SSH для Entware. На следующем шаге приложение проверит совместимость.

Сверьте отпечаток SSH с сохранённым отпечатком роутера в вашем SSH-клиенте.

Первая настройка роутера

Для установки на самом роутере нужны компоненты «Клиент прокси» и WireGuard, а также Entware на постоянном накопителе. Это может быть USB-диск, M.2 или поддерживаемое моделью встроенное хранилище. Порт SSH указан в журнале запуска Entware.

На роутере нет Entware? Автовыбор серверов может выполнять постоянно включённый компьютер или NAS.

Автоматическая подписка

Вставьте ключ со списком серверов из Happ, INCY или от вашего провайдера.

Параметры от провайдера

Роутер будет проверять доступность серверов и выбирать выход для новых соединений.

Подписка на роутере

Отдельный VPN-шлюз

Шлюз с Docker Compose будет выбирать сервер из подписки. Роутер можно подключить по SOCKS5 или через отдельный Ethernet-порт Linux-шлюза.

Параметры от провайдера

Архив содержит ключ подписки и новый пароль SOCKS5. Сохраните его для себя и перенесите на шлюз.

Как подключить роутер

Закрепите IP шлюза и распакуйте архив на компьютере с Docker Compose. Порядок запуска указан в README.md. Если на роутере есть «Клиент прокси», добавьте в «Другие подключения» SOCKS5 из архива и назначьте его нужным устройствам.

Если роутер поддерживает только обычный Ethernet WAN, используйте инструкцию ethernet/README.md. Понадобятся Linux-шлюз с отдельным Ethernet-портом и возможность задать статический IPv4 на WAN.
